## Install

You will need [pnpm](https://pnpm.io/installation) to run this web app.

Install dependencies with:

```bash
pnpm install
```

## Develop

Run a development server with:

```bash
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Verify

Run all checks (format, lint incl. typecheck, tests, build) before pushing. CI runs the same command:

```bash
pnpm run verify
```

## Deploy

Deployment is done manually by triggering a GitHub workflow. See how [here](https://docs.github.com/en/actions/managing-workflow-runs/manually-running-a-workflow).
